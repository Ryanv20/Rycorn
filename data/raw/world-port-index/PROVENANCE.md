# World Port Index Data

This directory contains the World Port Index source data.

## Expected Files

- `UpdatedPub150.csv`
- `Pub150bk.pdf` (optional, for reference)

## Source Details

- **Publication Date**: August 31, 2019
- **Source**: National Geospatial-Intelligence Agency (NGA) - Pub 150
- **Version**: data through 2019-08-31

## Action Required

The developer must download the NGA WPI CSV (`UpdatedPub150.csv`) and place it here.
The ingestion pipeline expects this file to exist and parses it directly without modification.

Do not alter the raw CSV file.
