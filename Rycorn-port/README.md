# Rycorn — Port

Standalone single-port operations dashboard for the Rycorn workspace. The current screen is a UI prototype with sample terminal activity and a CSS-built yard illustration.

Start it from the repository root:

```bash
pnpm dev:port
```

Vite serves the app at `http://localhost:5175` by default. The app is intentionally separate from the multi-region simulator client and can evolve into a port-specific operating system.
